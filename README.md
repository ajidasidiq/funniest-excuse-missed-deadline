One deadpan excuse an AI agent gives for missing a deadline, written the way the agent would say it to whoever is waiting. The excuse grows out of the agent's own machinery — it did submit the work, to an endpoint that answered like a real one — and the laugh lands on the last word, with nothing explained after it.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`.
